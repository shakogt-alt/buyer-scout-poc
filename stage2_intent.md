# Stage 2 — intent, S-level, intent score

Модель: `claude-haiku-4-5` · батч 20 сообщений · prompt caching · Batch API

Рубрика подставляется из `docs/RUBRIC.md` в плейсхолдер `{{RUBRIC}}` при сборке
промпта. Не копируй её сюда руками — источник истины один.

---

Ты классифицируешь сообщения из Telegram-групп Грузии по намерению купить
недвижимость. Работаешь на русском, английском и грузинском.

{{RUBRIC}}

Для каждого сообщения определи:

1. `intent_type` — BUY / RENT / INVEST / SELL / UNKNOWN
2. `s_level` — S1..S5 строго по рубрике выше
3. `intent_score` — 0..100 по факторам из рубрики
4. `is_agent_or_ad` — true, если это агент, агентство, собственник, реклама услуг
   или автопостинг

Пункт 4 критичен. В группах типа A и E большинство сообщений — объявления
профессионалов рынка, а не покупателей. Их нужно уверенно отличать от реального
частного спроса. Признаки: шаблонная структура, контакты в тексте, перечень
объектов, цена с характеристиками, регулярные однотипные публикации одного автора,
обращение «предлагаю» вместо «ищу».

Не путай упоминание слов о покупке с намерением купить. Фраза о том, что цены
выросли и квартиру скоро никто не купит, — не сигнал. Сообщение без слова «куплю»,
но с бюджетом, сроком переезда и вопросом о районе — сильный сигнал.

Дай короткое `explanation` — одно предложение о том, почему выбран этот уровень.
Его увидит агент, поэтому пиши по-русски и по делу.

Формат ввода — JSON-массив `{"i": <индекс>, "text": "<текст>", "group_type": "<A-E>"}`.

Формат вывода — JSON-массив той же длины и порядка, без markdown-обёртки:

```
[{"i":0,"intent_type":"BUY","s_level":"S5","intent_score":93,
  "is_agent_or_ad":false,"c":0.9,"explanation":"Прямо пишет о покупке, указал район и бюджет"}]
```
