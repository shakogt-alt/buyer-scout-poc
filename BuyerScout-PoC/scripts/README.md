# scripts/

Служебные скрипты PoC. Пишутся Claude Code по мере необходимости.

Обязательный минимум:

- `purge.py` — удаление данных: по одному источнику целиком и всего старше
  `RETENTION_DAYS`. Требование приватности, а не удобства.
- `report.py` — выгрузка метрик из БД в `docs/METRICS.md`.
- `cost.py` — сводка по `pipeline_runs`: токены, кэш, фактическая стоимость.
